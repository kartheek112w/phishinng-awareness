# Task 2 — Phishing Awareness Training

A local, self-contained awareness module with a lesson, realistic but fictional examples, and an interactive multiple-choice quiz.

## Run
Open `index.html` in a modern browser. No server, account, or external service is required.

## Learning outcomes
- Recognize sender and domain mismatches.
- Inspect links without opening suspicious destinations.
- Identify urgency, impersonation, unexpected attachments, and credential requests.
- Report suspicious messages through an organization's approved channel.

## Safety
All examples are fictional and use reserved example domains. The module does not send email, collect credentials, or contact any external website.
